## 🌟 About Scrapiz

Scrapiz is India's leading online scrap collection and recycling platform that transforms waste management through technology. We provide hassle-free doorstep pickup services for all types of scrap materials, offering transparent pricing and instant payments to customers across Mumbai and surrounding areas.

### 🎯 Mission
To empower individuals and businesses to manage waste responsibly by providing a seamless, transparent, and rewarding platform for selling scrap while promoting environmental sustainability.

### 🔮 Vision  
To be India's most trusted and comprehensive circular economy platform, creating a zero-waste ecosystem for a sustainable future.

## 🚀 Key Features

- **📱 Easy Online Booking**: Simple web interface for scheduling scrap pickups
- **🏠 Doorstep Collection**: Convenient pickup from your location
- **💰 Transparent Pricing**: Fair market rates with instant price calculator
- **⚡ Quick Payments**: Immediate payment upon collection
- **🌍 Eco-Friendly**: Promoting responsible recycling and waste management
- **📍 Wide Coverage**: Serving Mumbai and surrounding areas
- **📊 Real-time Tracking**: Track your pickup status in real-time

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rahim8828/Scrapiz-Website-Latest.git
   cd Scrapiz-Website-Latest
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 📝 Available Scripts

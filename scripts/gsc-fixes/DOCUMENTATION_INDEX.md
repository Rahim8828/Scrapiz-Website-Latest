## Reference by Use Case

### "I want to..."

#### Run an Audit
1. Read: [AUDIT_SCRIPT_README.md](./AUDIT_SCRIPT_README.md)
2. Run: `node scripts/gsc-fixes/audit-all-issues.js`
3. Review: Generated reports in `scripts/gsc-fixes/reports/`

#### Apply Fixes
1. Read: [AUTOMATED_FIX_QUICK_START.md](./AUTOMATED_FIX_QUICK_START.md)
2. Read: [AUTOMATED_FIX_README.md](./AUTOMATED_FIX_README.md)
3. Run: `node scripts/gsc-fixes/apply-all-fixes.js --dry-run`
4. Run: `node scripts/gsc-fixes/apply-all-fixes.js`

#### Submit to Google Search Console
1. Read: [GSC_SUBMISSION_CHECKLIST.md](./GSC_SUBMISSION_CHECKLIST.md)
2. Read: [MANUAL_STEPS_GUIDE.md](./MANUAL_STEPS_GUIDE.md)
3. Follow checklist step-by-step

#### Fix a Specific Issue Type
- **Soft 404**: [Soft404.README.md](./Soft404.README.md)
- **Canonical**: [Canonical.README.md](./Canonical.README.md) + [CANONICAL_QUICK_START.md](./CANONICAL_QUICK_START.md)
- **Redirects**: [Redirect.README.md](./Redirect.README.md) + [REDIRECT_QUICK_REFERENCE.md](./REDIRECT_QUICK_REFERENCE.md)
- **Noindex**: [Noindex.README.md](./Noindex.README.md)
- **Duplicates**: [Duplicate.README.md](./Duplicate.README.md)
- **404 Errors**: [NotFound.README.md](./NotFound.README.md)
- **Schema**: [Schema.README.md](./Schema.README.md) + [SCHEMA_MAINTENANCE_GUIDE.md](./SCHEMA_MAINTENANCE_GUIDE.md)

#### Set Up Monitoring
1. Read: [MONITORING_QUICK_START.md](./MONITORING_QUICK_START.md)
2. Read: [Monitoring.README.md](./Monitoring.README.md)
3. Run: `node scripts/gsc-fixes/monitor-indexing.js`
4. Set up cron job

#### Troubleshoot an Issue
1. Read: [TROUBLESHOOTING_GUIDE.md](./TROUBLESHOOTING_GUIDE.md)
2. Check relevant module README
3. Review error logs in `scripts/gsc-fixes/logs/`
4. Run example workflow for the module

#### Understand How Something Works
1. Check module README (e.g., [Canonical.README.md](./Canonical.README.md))
2. Review implementation doc (e.g., [CANONICAL_IMPLEMENTATION.md](./CANONICAL_IMPLEMENTATION.md))

## Documentation Maintenance

### Adding New Documentation

When adding new features:
1. Create module README (e.g., `NewModule.README.md`)
2. Create implementation doc (e.g., `NEWMODULE_IMPLEMENTATION.md`)
3. Create example workflow (e.g., `example-newmodule-workflow.js`)
4. Add unit tests (e.g., `test-newmodule-unit.js`)
5. Update this index
6. Update main [README.md](./README.md)
7. Update [COMPLETE_SCRIPT_REFERENCE.md](./COMPLETE_SCRIPT_REFERENCE.md)

### Documentation Standards

- Use Markdown format
- Include code examples
- Provide usage instructions
- Document parameters and return values
- Include troubleshooting sections
- Add cross-references to related docs
